## 📌 Descripción

**FitFlex AI** es una aplicación web interactiva de alto rendimiento orientada al seguimiento de fuerza y acondicionamiento físico. Integra asistencia por IA para estructurar entrenamientos personalizados y ofrece una experiencia de uso fluida con animaciones cuidadas, feedback visual y sincronización entre móvil y escritorio sin fricciones.

🔗 **Acceso a la app:** [fit-flex-ai-omega.vercel.app](https://fit-flex-ai-omega.vercel.app)

---

## ✨ Características Principales

* 🧠 **Rutinas Adaptadas con IA:** Creación y ajuste dinámico de entrenamientos según nivel y objetivos.
* ⚡ **Registro Ágil en Sala:** Control de series, repeticiones, peso y tiempos de descanso con interfaz táctil optimizada.
* 🔄 **Sincronización Híbrida:** Persistencia inmediata en `LocalStorage` con replicación en la nube mediante `KVDB REST API` para continuar tu sesión en cualquier dispositivo.
* 🎬 **Experiencia Visual Fluida:** Animaciones entre vistas y micro-interacciones construidas con `Framer Motion`.
* 🎉 **Feedback de Logros:** Efectos de confeti interactivos (`Canvas Confetti`) al batir récords y completar sesiones.
* 📱 **Mobile-First & Responsive:** Interfaz moderna adaptada a cualquier tamaño de pantalla.

## 🛠️ Stack Tecnológico

| Área | Herramientas / Librerías | Propósito |
| :--- | :--- | :--- |
| **Core & Framework** | `React 19` + `Vite 8` | Arquitectura basada en componentes y compilación ultra rápida. |
| **Estilos & UI** | `Tailwind CSS v4` + `Lucide React` | Maquetación moderna, diseño responsive e iconografía vectorial. |
| **Animaciones** | `Framer Motion` + `Canvas Confetti` | Transiciones de pantalla, micro-interacciones y efectos de celebración. |
| **Persistencia** | `LocalStorage` + `KVDB REST API` | Almacenamiento local con sincronización en la nube multidispositivo. |
| **Calidad de Código** | `Oxlint` | Linter de alto rendimiento en Rust para garantizar código limpio. |
| **Despliegue** | `Vercel` | Hosting y entrega continua optimizada. |
